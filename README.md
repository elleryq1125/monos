# 在庫管理システム「monos」

## 1. 概要
商品・倉庫単位に在庫を管理するWebアプリケーションです。

入出庫の予定・実績登録により在庫の増減が行えます。

個人開発として、要件定義～テスト、AWSへのデプロイ、CI/CD構築まで一通り実施しました。

## 2. デモ
🌐 **デモサイト**

https://monos-app.com

デモ環境では、あらかじめサンプルデータを登録しています。

ログイン後、商品・倉庫登録機能、入出庫予定・実績登録などの機能を実際に利用できます。

※デモ環境のため、ログインユーザーの新規登録・追加機能は停止しています。

## 3. 主な機能
- ユーザー認証
- 商品管理
- 倉庫管理
- 入庫予定・実績管理
- 出庫予定・実績管理
- 在庫管理
